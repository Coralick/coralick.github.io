# Редизайн карточки товара Teaboom

Адаптивная верстка верхней части карточки товара «Ананасовый улун» в стилистике Teaboom.ru. Проект выполнен на HTML5, CSS и чистом JavaScript без фреймворков и готовых шаблонов магазина.

## Требования из ТЗ

- Сверстать верхнюю часть карточки товара «Ананасовый улун».
- Показать изображение, название, категорию, фасовки, артикул, актуальную и старую цену, кнопку «В корзину» и короткое описание.
- Поддержать фасовки:
  - 100 г — арт. 01306 — 349,20 ₽ → 326,40 ₽;
  - 500 г — арт. 01307 — 1 646 ₽ → 1 432 ₽;
  - 1000 г — арт. 01308 — 2 592 ₽ → 2 064 ₽;
  - 5000 г — арт. 01309 — 8 710 ₽ → 6 320 ₽.
- При переключении фасовки менять цену, старую цену, артикул и выбранное состояние.
- Сделать обычное и hover-состояние кнопки «В корзину»; реальную корзину не подключать.
- Обеспечить корректное отображение на 1440, 768 и 375 px.
- Использовать HTML5, CSS/SCSS, JavaScript и Flexbox/Grid.
- Сохранить семантически понятную структуру HTML и аккуратную структуру проекта.
- Не использовать Bootstrap, крупный frontend-фреймворк, готовые шаблоны магазина, backend или Django.
- Можно использовать изображения и информацию с действующего сайта Teaboom.ru.
- Результат должен соответствовать общей стилистике Teaboom.ru; допускается улучшение визуальной подачи без полного редизайна сайта.

## Запуск

Проект не требует сборки и зависимостей.

1. Откройте `index.html` в браузере; или
2. Запустите любой локальный статический сервер из папки проекта, например Live Server.

## Реализовано

- интерактивное переключение четырех фасовок;
- пересчет отображаемой экономии;
- hover/focus-состояния кнопок;
- демонстрационное добавление в корзину без backend;
- избранное и адаптивное мобильное меню;
- доступные radio-переключатели, aria-live для обновляемых данных и поддержка reduced motion;
- адаптивные компоновки для desktop, tablet и mobile.

Изображение товара и знак логотипа взяты с Teaboom.ru и сохранены локально для демонстрационной верстки.
